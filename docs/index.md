# BASA Chatbot Documentation

## Overview

BASA Chatbot is a Laravel-based chatbot application that uses RAG (Retrieval-Augmented Generation) to provide context-aware responses from document files and webpages.

## Structure

```
docs/
├── index.md              # Main documentation page
├── installation.md       # Installation and setup instructions
├── configuration.md      # Configuration options and environment variables
├── usage.md             # Usage guide and examples
├── api.md               # API documentation
├── development.md       # Development guide
├── diagrams/            # Diagrams and visual documentation
│   ├── generate_ipo_diagram.py  # Diagram generation scripts
│   └── chatbot_ipo.png         # Generated diagrams
└── _static/            # Static files like CSS, JS, images
```
